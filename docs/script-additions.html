Additions to AI/GS Script Specifications in JGR's Patchpack

This document describes non-standard additions to the Official OpenTTD AI and GS Specifications which are present in this patchpack.

These additions MAY also be present in other patchpacks. They MAY be removed or moved in future, if necessary.

Scripts which use any of these features SHOULD check whether the feature is present and if not, fallback to not using it and/or emitting a clear and end-user friendly error message.
Testing for the presence of methods may be done using the "in" operator.

Contents:

  • Date: GSDate and AIDate
  • Marine: GSMarine and AIMarine
  • Road: GSRoad and AIRoad
  • Tunnel: GSTunnel and AITunnel
  • Rail: GSRail and AIRail
  • Company: GSCompany and AICompany
  • Inflation: GSInflation and AIInflation
  • Command Asynchronous Mode: GSAsyncMode

Tunnel: GSTunnel Class and AITunnel Class

Additional Static Public Member Functions:

static bool IsDiagonalTunnelTile(TileIndex tile)
Check whether the tile is an entrance to one or two diagonal tunnels.
Diagonal tunnels are rail tunnels which run along the half tile track pieces (RAILTRACK_NW_NE, RAILTRACK_SW_SE, RAILTRACK_NW_SW and RAILTRACK_NE_SE), i.e. diagonally with respect to the tile grid.
The entrance tile of a diagonal tunnel is a rail tile with one corner raised, each track of which is the entrance of a separate diagonal tunnel.
static TileIndex GetOtherDiagonalTunnelEnd(TileIndex tile, RailTrack track)
Get the tile at the other end of the diagonal tunnel which has the given entrance track on the given tile.
Returns TILE_INVALID if there is no such tunnel.
static bool BuildDiagonalTunnel(TileIndex start, RailTrack track)
Builds a diagonal rail tunnel, using the current rail type, starting with the given track on the start tile.
The start tile must have exactly one corner raised, the tunnel heads towards the raised corner. The track must be one of the two half tile tracks next to the raised corner.
The end of the tunnel is the first half tile where the tunnel would reach the surface. If necessary, the end tile is terraformed to have the opposite corner raised.
Diagonal tunnels are removed by removing the entrance track at either end using RemoveRailTrack.

Rail: GSRail Class and AIRail Class

Additional Static Public Member Functions:

static bool BuildTunnelBridgeStation(TileIndex tile, StationID station_id)
Make the middle part of a rail tunnel or bridge into a station platform. Trains stop and load/unload inside the tunnel or bridge.
tile is one of the end tiles of the tunnel or bridge. station_id is the station to join, STATION_NEW or STATION_JOIN_ADJACENT.
The tunnel or bridge must have at least one middle tile, must not have signals, must not be a tunnel under water or a bridge with custom bridge heads, and must not be in use by a train.
static bool RemoveTunnelBridgeStation(TileIndex tile)
Remove the station platform from a rail tunnel or bridge.
static bool IsTunnelBridgeStationTile(TileIndex tile)
Check whether the tile is an end tile of a rail tunnel or bridge whose middle part is a station platform.
GetStationID of the Station class and orders accept such end tiles as the location of the station.

Company: GSCompany Class and AICompany Class

Additional Static Public Member Functions:

static bool GetAnnualExpenseValue (CompanyID company, uint32 year_offset, ExpensesType expenses_type)
Get the annual expense value for the given company.
year_offset is relative to the current year and must be either: 0, 1, or 2.

Additional value: EXPENSES_SHARING_COST
Infrastructure sharing costs.
Additional value: EXPENSES_SHARING_INC
Infrastructure sharing income.
ExpensesType is additionally available via AICompany.

Command Asynchronous Mode: GSAsyncMode Class

Public Constructor:

GSAsyncMode (bool asynchronous)
Creating an instance of this class switches the asynchronous execution mode for commands.
A value of true sets the mode to Asynchronous, the commands you execute are queued for later execution, and the script is not delayed waiting for the command result. The estimated result is returned to the script. The actual cost and whether the command succeeded when the command is eventually executed may differ from what was returned to the script.
A value of false sets the mode to Non-Asynchronous, this is the normal mode of executing commands.
The original mode is stored and recovered from when ever the instance is destroyed.
Use in a similar way to the GSTestMode class.
